# 嘉立创工艺规格与 Minibox PCB 设计规范

核对日期：2026-10-09。适用于嘉立创国内站常规 FR-4 PCB 和 Minibox 四层板。
本文是相关工艺参数的摘要，不是工厂验收承诺；下单时以所选板厚、铜厚、
阻焊颜色、服务类型和工程审核为准。特殊工艺不能直接套用常规数值。

## PCB 加工能力与推荐设计值

以下单位为 mm，铜厚单位为 oz；1 mil = 0.0254 mm。
“官方能力”可能是极限或收费选项；“项目推荐”是设计裕量，不是官方极限。

| 项目 | 官方能力/条件 | Minibox 推荐设计 |
|---|---|---|
| 层数、板料 | FR-4 支持 1–64 层 | 四层；选定实际叠层后再确定阻抗几何 |
| 板厚 | 0.4–4.8，实际以系统可选项为准 | 优先评估 1.6；先核对连接器、外壳及叠层 |
| 外/内层铜厚 | 多层外层 1/2；内层 0.5/1/2 | 不假定内层与外层等厚；载流按订单铜厚计算 |
| 多层 1 oz 最小线宽/线距 | 0.09/0.09；BGA 局部线宽可达 3 mil | 常规信号 0.20/0.20；细间距逃线需单独审核 |
| 多层 2 oz 最小线宽/线距 | 0.15/0.15 | 换铜厚必须重新检查线距、阻焊和阻抗 |
| 线宽公差 | ±20% | 不以极限线宽做大电流路径 |
| 1 oz 焊盘边到线边 | ≥0.10；多层 BGA 局部 ≥0.09 | 常规 ≥0.20；封装内部特殊间距单独确认 |
| 多层机械钻孔 | 最小 0.15，属非常规且费用高；推荐最小孔 ≥0.20 | 普通过孔钻孔 0.30 |
| 普通过孔焊盘 | 最小内/外径 0.15/0.25；外径比内径大 ≥0.10，推荐大 ≥0.15 | 外径/钻孔 0.60/0.30；径向焊环 0.15 |
| 过孔孔边间距 | ≥0.20 | ≥0.25，并保留制造裕量 |
| 多层有铜插件孔焊环，1 oz | 径向 ≥0.20 为建议值，极限 0.15 | ≥0.20；不得沿用过孔的 0.10 最小焊环 |
| 插件孔孔边间距 | ≥0.45 | ≥0.45；与普通过孔区分检查 |
| 插件孔成品孔径公差 | +0.13/−0.08 | 按引脚最大尺寸、装配余量核对最小成品孔 |
| NPTH 孔径公差 | ±0.10 | 按螺钉/定位柱最大尺寸和机械公差核对 |
| 多层有铜槽 | 最小宽 0.35、长 0.70；槽长宜 ≥2 倍槽宽 | 采用器件厂家推荐孔槽，确认 PTH 属性 |
| 无铜槽 | 最小宽 1.00 | 在唯一外形/加工定义中明确，不用禁布区代替 |
| 锣边铜到边/槽 | ≥0.20 | ≥0.50；所有铜层、焊盘、过孔均检查 |
| V 割铜到分板线 | ≥0.40 | ≥0.50；圆角板优先评估锣边/邮票孔方案 |
| 锣边尺寸公差 | 普锣 ±0.20；精锣 ±0.10，有额外条件 | 将公差计入插座、螺钉和外壳间隙 |
| 板厚公差 | ≥1.0 时 ±10%；<1.0 时 ±0.10 | 1.6 板按 1.44–1.76 评估配合 |
| 丝印字高/笔画 | ≥1.00 / ≥0.10 | ≥1.00 / ≥0.15，优先更大 |
| 丝印到露铜焊盘 | ≥0.15 | ≥0.20；不压焊盘、不被器件遮挡关键极性标记 |
| 阻焊桥，1 oz | 焊盘边距 ≥0.10：绿/红/黄/蓝/紫；≥0.13：黑/白 | 精细封装优先绿色；按实际开窗检查剩余桥宽 |
| 阻焊桥，2 oz | 焊盘边距 ≥0.20，各颜色 | 铜厚变化后重新检查 |
| 阻抗公差 | 官方表列 ±10%，收费 | USB 目标 90 Ω 差分；须确认结构、几何及订单阻抗服务 |

**焊环是径向宽度**，即外径与孔径之差的一半；不能把“外径大 0.10”
误填为“径向焊环 0.10”。过孔、插件孔、NPTH 的要求也不能互换。
官方表的插件孔/NPTH 尺寸公差不应直接当作所有过孔的通用公差。

官方能力表说明 2025 年 6 月起使用 LDI，焊盘与阻焊开窗按 1:1 制作，
也允许客户资料按单边 ≥0.02 设计后由工程调整。应结合实际封装与工厂
审核选择开窗，不能机械地给所有焊盘扩大同一个数值。
“焊盘边距门槛”不是最终阻焊桥宽；要看开窗扩张后的真实间隔。

过孔双面盖油/帐篷覆盖不等于树脂塞孔、填平和电镀盖帽。
普通四层板不默认包含盘中孔工艺；焊盘内钻孔、QFN 散热孔和细间距
焊盘附近的孔应确认吸锡、平整度、阻焊及钢网方案，未确认则避免盘中孔。

## SMT 服务：不要混用经济型与标准型

下表取自同一官方页面的 SMT 标签；封装代码沿用官网标记，下单须核对实际尺寸。

| 项目 | 经济型 | 标准型 |
|---|---|---|
| 焊接面 | 单面，贴片+插件 | 单/双面，贴片+插件 |
| PCB 层数 | 2/4/6 | 表列无限制，仍需订单审核 |
| 板厚 | 0.8–1.6 | 表列无限制，仍受 PCB 工艺约束 |
| 尺寸 | 10×10 至 470×570 | 70×70 至 460×510 |
| 数量 | 样板 ≤30(50) 大片，按平台具体方案确认 | 2 片起贴 |
| 出货方式 | 单板、邮票孔拼板 | 单板、邮票孔拼板、V 割拼板 |
| 工艺边 / Mark 点 | 官网表列不需要 | 需要 |
| 最小封装 / IC 引脚间距 | 0402 / 0.40 | 01005 / 0.35 |
| BGA 球间距 | 0.50 | 0.30 |
| 回流温度 | 255±5 °C，不可调 | 可选择低/中/高温范围，按器件与工艺确认 |
| SPI / AOI | 官网表列无 | 官网表列单独检测 |

100×88 mm、四层、正面装配在上述尺寸/层数范围内，
**但不意味着全部器件已获准贴装**。必须核对具体 MPN、立创料号、
库存、封装、焊接温度、极性、供应方式和插件/异形件工序。
LCD 母座、摇杆、MX 开关、电池座、端子及 USB 固定脚应逐项确认，
不能把“支持插件”理解为所有插件都自动完成或已包含费用。

标准型工艺边按官方 PCB 表中 SMT 说明至少 5 mm，Mark 直径 1 mm、
定位孔 2 mm，光点到板边 3.85 mm；光点距离口径、位置、数量及
阻焊避让应按工厂模板确认。经济型不能被误写为必须有这套工艺边。
工艺边通常加在拼板上，不得未经确认改动成品板外形。

## Minibox 四层布局与布线规则

### 叠层和回流

- F.Cu：器件及主要信号；In1.Cu：连续 GND；In2.Cu：电源及必要的 GND 参考区；
  B.Cu：辅助信号。`kicad_ex` 所有器件在正面，背面不新增器件。
- 连续地层不表示可以忽略天线禁铜、NPTH、孔槽和机械安全区域。
  ESP 天线禁区按模块数据手册在相关层实施。
- I2S 优先 F.Cu，参考相邻 In1 GND。B.Cu 旁边是 In2：
  若 In2 分割电源，底层高速信号不得跨分割；优先改回顶层，
  必要时规划连续 In2 GND 通道并验证其与主地的连接。
- 信号换层时安排附近 GND 回流过孔，连接实际参考地；距离按几何和
  信号边沿评估。不要把孤立、悬空的地过孔当作回流路径。
- GND 包地是辅助，不能替代完整参考平面。包地必须连主地、适当缝合，
  避免浮铜、狭长地颈和断续围栏；不得为包地强行压缩信号间距。

### 几何与信号质量

- **本项目禁止直角和锐角走线**，采用 45° 转角或圆弧。
  这是用户要求和项目规范，官方能力表没有将直角列为统一拒收条件。
  应检查同层相邻线段的真实转角、T 分支和铺铜尖角，不只看路由器设置。
- USB 差分对先布；保持成对、同层、相同参考、尽量相同换层次数，
  减少脱耦段、支线、无必要过孔和保护器件造成的不对称。
  Type-C 重复数据引脚要正确合并，不能横穿另一网络而短路。
- USB 的 90 Ω 是电气目标；当前候选 0.20 线宽/0.25 间距不是阻抗合格证明。
  必须按工厂叠层计算，再核对器件脚扇出、邻近铜和过孔。
  长度差预算按 USB PHY/保护器件资料和实际速率确定，不编造通用阈值。
- I2S 按信号上升沿而不是只按音频采样率评估；源端阻尼靠近真正驱动端，
  BCLK/WS 的分支尽量短，保持麦克风数据与扬声器数据方向正确。
  不强行把所有 I2S 线做等长蛇形线，按器件建立/保持时间制定预算。
- MAX 功放输出为开关功率信号，不是 I2S；扬声器两线均不是 GND。
  远离 INMP 麦克风、其供电和 I2S；核对麦克风声孔、板孔和装配方向。
- 降压输入电容、开关回路、电感、输出电容与反馈按芯片推荐布局；
  SW 铜面积控制在必要范围，反馈远离 SW，不交给自动布线器随意绕行。
- 3 A 路径不能默认使用 0.20 信号线宽。根据实际铜厚、层别、长度、
  温升、压降和热环境计算线宽/铜面与过孔数量；检查焊盘入口、保险丝、
  二极管、连接器及热焊盘的最窄瓶颈。引用 IPC-2152 等方法时记录条件。

### 布局与装配

使用器件真实 courtyard 和最大实体/装配包络，而不只看丝印或包围矩形。
核对键帽、电池、插头、螺钉、工具操作及外壳公差；正面放置本身不等于无冲突。
去耦靠近电源引脚、回地短；地铜不能侵入天线及声学/机械禁区。
不得为解决布线困难擅自增加电源管理器件或删掉必要保护和去耦。

## KiCad 规则落地和发布门槛

将上述规则落实到 Board Setup、网络类及必要的自定义 DRC 规则。
特别注意：**全局最小间距、网络类间距、封装局部覆盖是不同约束**；
网络类 0.20 不表示全局已设为 0.20。插件孔焊环/孔间距应单独检查，
不能仅凭全局过孔规则判断合格。丝印高度、笔画和到焊盘距离也须显式设置。

核查时发现 `kicad_ex` 的全局文字门槛仍为 0.80/0.08，低于本文的官方
1.00/0.10；全局孔间距 0.25 也不能替代插件孔 0.45 检查。
这是待落实项，本文没有修改 PCB 规则或宣称现有布线达标。

发布前必须：重新填充全部铜区；ERC、DRC、未连接和原理图一致性检查；
额外检查直角、差分几何、信号参考层、载流瓶颈、机械干涉及真实 BOM。
所有问题修复；确实必要的例外须逐项记录理由并获确认，不得整类屏蔽。
**零 DRC 不等于阻抗、EMC、载流、声学或装配全部合格。**

工厂资料应包括四个铜层及所需阻焊/丝印/外形 Gerber、分开的 PTH/NPTH
钻孔文件、BOM、CPL/坐标、装配图、极性/Pin 1 说明、叠层及阻抗说明、
插件/异形件清单。钢网开口按工厂要求确认；审核 Gerber 和装配预览，
验证 CPL 原点、单位、正反面和旋转角，不直接假定 KiCad 角度适配工厂。

未完成布线或料号审核的导出件必须标记“草稿，不可生产”。
上述文档和 skill 的建立不改变 `kicad_ex` 尚未达到生产发布门槛的状态。
