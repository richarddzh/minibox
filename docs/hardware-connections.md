# 模块参数与接线

本文集中维护 Minibox 的实际模块接线。修改硬件时同步更新本文和固件配置，
避免文档与接线不一致。

## 主控：ESP32-S3 N16R8

| 参数 | 值 |
|---|---|
| 芯片 | ESP32-S3，实板识别 revision v0.2 |
| Flash | 16 MB，Quad SPI，3.3 V |
| PSRAM | 8 MB，Octal，3.3 V |
| 固件 Flash 配置 | DIO，80 MHz |
| 固件 PSRAM 配置 | Octal，40 MHz |
| 当前电脑串口 | **COM8**，USB-Enhanced-SERIAL CH343 |
| 串口日志 | UART0，115200 波特率 |
| 固件项目 | [`esp32_idf_s3n16r8`](../esp32_idf_s3n16r8/README.md) |

COM8 是当前 Windows 分配的端口，更换电脑或 USB 接口后可能变化。
GPIO19/20 保留给原生 USB；不使用 GPIO35/36/37，以避免与 N16R8
Octal PSRAM 冲突。

## 按载板布局分配 GPIO

依据 [ESP32-S3-DevKitC-1 v1.1 官方排针表](https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.1.html#user-guide-s3-devkitc-1-v1-1-header-blocks)
分配：左侧摇杆使用 GPIO1/2 的 ADC1，左侧功放的时钟和 DIN 使用
GPIO39/40/41，RTC 使用 GPIO15/16；四个机械轴使用 GPIO4/5/6/7，
屏幕仍使用 GPIO9–14。GPIO40/41 **没有 ADC**，不能直接读取模拟摇杆。
GPIO0/3/45/46 启动配置脚、GPIO19/20 原生 USB、GPIO43/44 UART0、
GPIO35/36/37 Octal 存储器，以及 GPIO38/48 板载 RGB 候选脚均不接外设。
GPIO39–41 已用于 I2S，不能同时使用这些排针做外部 JTAG 调试。
GPIO42 已释放，摇杆按压功能不用；GPIO8/18 同样未连接。
GPIO17 接麦克风 SD。官方 v1.1 的 RGB 使用 GPIO38，
当前实板固件仍保持 GPIO48，须按实际开发板确认，不因网页版本自动改动。

与旧载板相比，音频、键盘、摇杆及 RTC 的 GPIO 分配已变化；
**新 PCB、固件和实物线缆必须配套使用**，不要混用旧接线。

载板外部 5 V 正极先接三针开关的电源端，外部 GND 接开关 GND；
开关负载端给开发板 **5V** 排针及 MAX98357A VIN 供电。开发板的
**3V3** 排针再给屏幕、麦克风、RTC 和摇杆供电；机械轴仅接 GPIO/GND。
载板 J8 为 5.08 mm 双位接线端子（正面从上到下：5V 输入、GND），
J7 为 5.08 mm 三位接线端子（正面从上到下：开关 GND、
开关负载端、开关电源端）；请优先按焊盘号及网名核对，不沿用旧方向。
J9 是独立 CC1/CC2 双位端子；J8/J9 进线向左，J7 进线向右。
键盘轴及摇杆直接焊接；其余模块维持 2.54 mm 母座。
[`接线端子参考图`](../assets/crimp_terminal.jpg)仅确认节距，
购料前还要核对所购接线端子的实物针脚与 KiCad 封装。
载板所有排母和接线端子均从正面插装、背面焊接，采用双面开窗的
镀通孔焊盘：排母孔径 1.0 mm、焊盘 1.7 mm；J7/J8 孔径 1.3 mm、
焊盘 2.6 mm（包括 J9）。四层版本的 GND 焊盘通过热焊盘连接内层地平面，
包括 J1 第 22 脚及 J5 第 6 脚，不再依赖原双层板的专用地线走线。
模块信号引脚丝印保留功能名称并标注
连接的 GPIO 编号，未连接信号标为 NC；标签以正面视角为准。
为背面手工焊接留出余量，J7 第 1/2 脚和 J8 第 1 脚的 5V 焊盘
在全部四个铜层与 GND 覆铜及其他网络保持至少 0.5 mm 铜间距；
其余覆铜采用 0.35 mm 间距，普通走线采用 0.20 mm 间距。
3.3 V 由开发板上的稳压器产生，而非 ESP32-S3 芯片自行转换。
必须核实实际开发板稳压器的可用电流，以及 USB 与外部 5 V
同时连接时是否会反灌；不能把开发板的 3V3 脚接到开关负载 5 V。

2026-10-09 改版外形为 **94.5 × 117 mm、R5 圆角**。
相对旧 100 × 112 mm，包围矩形面积减少约 1.28%，不是大幅压缩。
四个 Ø3.0 mm NPTH 安装孔为 (10,8)、(94.5,8)、(10,115)、(94.5,115)；
中心距 **84.5 × 107 mm**。旧外壳孔位不能沿用。
ESP32 USB 朝左，天线朝右；估算本体完整留在板内，四层天线禁铜区
X=81–99.5、Y=20.6–42.1 mm。估算外形不等于厂商机械图，实物须复核。
RTC 位于 ESP32 上方，含电池预留 27.5 × 12 mm，至 ESP32 约 3.03 mm；
MAX98357 平放预留 27 × 24 mm，下缘 Y=72，上排键帽上缘 Y=80.5。
水平分界线 Y=76，两侧各留 2 mm 安装隔离带：上方本体不超过 Y=74，
下方操作包络不早于 Y=78；该约束不禁止信号走线跨分界。
四轴中心距 19.05 mm，下排错开半单位 9.525 mm；
18 × 18 mm 是键帽允许最大包络，不是已确认键帽型号，邻帽间隙 1.05 mm。
摇杆竖放，中心 (22,93)，预留 **直径 30 mm / 半径 15 mm** 活动圈。
麦克风预留圈中心 (48.5,87.75)、直径 19.5 mm，位于左上键左侧、
左下键上方，间隙分别 2.00、2.05 mm；与摇杆活动圈间隙约 2.27 mm。
模块外形及 RTC 厚度是安装接受包络，必须用实际模块及电池确认。
麦克风安装两个独立 1×3 母座，排距 7.62 mm，不是普通 2×3 母座。
保留母座总计 7 条、77 个接点；另装三个压线端子、四个机械轴、
一个摇杆及两个 0402 电阻。所有器件从正面安装，插件背面焊接。
四层为顶层信号 / In1 连续 GND / In2 电源走廊及 GND / 底层信号；
I2S 顶层参考 In1，必要的底层分支参考 In2 地通道，换层附近缝合地。
信号 0.20 mm，3V3 0.65 mm，5V 0.80 mm，普通过孔 0.60/0.30 mm；
这些电源宽度不构成 3 A 载流承诺。名义板厚 1.6 mm，实际铜厚、
叠层、热设计及四层报价须经工厂复核。
实际状态、效果图及资料见 [`kicad/README.md`](../kicad/README.md)。

### Type-C 5 V 识别

外部 Type-C 母座的 VBUS/GND 接 J8，CC1/CC2 分别接 J9 第 1/2 脚；
R1/R2 各为 5.1 kΩ、0402、1%，独立从各 CC 拉到 GND，不得短接 CC1/CC2。
该电路只是普通 5 V 受电端 Rd 标识，不进行 USB-PD 协商，也不保证 3 A。
使用的外接 Type-C 小板若已带 Rd，不得再并联本板电阻。
本载板不接 USB 数据线。焊好后断电测量每条 CC 对地约 5.1 kΩ，
再用限流电源检查 5 V 极性、开关和稳压输出。

## 屏幕模块：ST7796 SPI

| 参数 | 值 |
|---|---|
| 控制器 | ST7796 |
| 显示分辨率 | **480 × 320**，横屏 |
| 显示朝向 | 横屏交换坐标轴（MV），清除 MX/MY 镜像；BGR 开启时 MADCTL=0x28 |
| 接口 | SPI，模式 0，SPI2_HOST |
| 默认 SPI 时钟 | 40 MHz，可配置为 1–40 MHz |
| 屏幕驱动 | 乐鑫 `espressif/esp_lcd_st7796` 1.4.0，纯 ESP-IDF |
| 像素格式 | RGB565，16 bit，高字节先发送 |
| 字体 | 24 px 中英文抗锯齿字体，存放在 SPIFFS，见[字体说明](display-fonts.md) |
| 默认色序 | BGR，可配置 |
| 默认反色 | 关闭，可配置 |
| 背光控制 | 默认高电平点亮，可配置极性 |
| 背光调制 | 无 PWM；启动点亮后保持恒定电平 |

| 屏幕引脚标识 | ESP32-S3 引脚 | 作用 |
|---|---|---|
| LED / BL | **GPIO9** | 背光控制 |
| SCK / CLK | **GPIO10** | SPI 时钟 |
| SDI / MOSI | **GPIO11** | 主控向屏幕发送数据 |
| DC / RS | **GPIO12** | 命令 / 数据选择 |
| Reset / RST | **GPIO13** | 硬件复位，低电平有效 |
| CS | **GPIO14** | 片选，低电平有效 |
| SDO / MISO（若有） | 不接 | 当前固件只写屏幕，不读取 ID |
| GND | GND | 与主控共地 |
| VCC | 3.3 V | 用户指定屏幕使用 3.3 V；实际模组额定范围和开发板 3.3 V 稳压器负载能力仍须核实 |

用户确认屏幕排针顺序与 [`tft_spi.jpg`](../assets/tft_spi.jpg)
相同：1 VCC、2 GND、3 CS、4 RESET、5 DC/RS、6 SDI(MOSI)、
7 SCK、8 LED、9 SDO(MISO)、10 T_CLK、11 T_CS、12 T_DIN、
13 T_DO、14 T_IRQ。当前固件不用 SDO 和触摸功能，9–14 脚不接。
参考图标为 **2.8 英寸 240×320**，本项目屏幕记录为
**4 英寸 480×320**；只据用户确认采用排针顺序，屏幕实际控制器、
排距、孔位和供电仍需核实，不能据参考图推断显示模组完全相同。

屏幕逻辑信号必须兼容 **3.3 V**。GPIO9 只能连接背光控制输入：
如果模块 LED 引脚是裸背光供电端，需采用额定限流和晶体管/MOSFET 驱动，
不能直接由 GPIO 承担背光电流。

屏幕接线常量位于
[`main/app_config.h`](../esp32_idf_s3n16r8/main/app_config.h)。
SPI 时钟、色序、反色和背光极性位于
`idf.py menuconfig` → `Minibox hardware test`。

## 四个直焊机械键盘轴

SW1–SW4 使用用户指定 HanElectricity **CPG151101D13 / C49234235**，
每轴触点 1 接各自 GPIO、触点 2 接 GND，按下闭合，无 VCC 接点。
取消 J11/J12 母座。触点孔 Ø1.50 mm，中心定位 NPTH Ø3.90 mm；
孔位由该型号图纸核对，不采用带额外 LED/定位柱的通用 MX 封装。

| 模块信号 | ESP32-S3 接线 | 当前功能 |
|---|---|---|
| SW1 触点 1 | **GPIO4** | 屏幕显示按下/松开 |
| SW2 触点 1 | **GPIO5** | 按住录音，松开回放 |
| SW3 触点 1 | **GPIO6** | 屏幕显示按下/松开 |
| SW4 触点 1 | **GPIO7** | 屏幕显示按下/松开 |
| 各轴触点 2 | **GND** | 共地；不能接 3.3 V |

默认按下输出低电平，使用 GPIO 内部上拉，每 10 ms 采样并做 30 ms
消抖。直焊轴必须保持菜单 `GPIO4/5/6/7 buttons pressed at low level`
开启；高有效选项仅保留给兼容的外接模块。

## 直焊摇杆：YV13S-L7.85-B10Ka(60)-0-DL01

JS1 为用户指定 YTL **C37323747**。六个电位器引脚为 Ø1.0 mm PTH，
VR1 滑动端 X2 接 GPIO1、VR2 滑动端 Y2 接 GPIO2；各自端点 1 接 GND，
端点 3 接 3.3 V。四个固定焊脚及四个按压焊脚保持无网络。
该型号本身有按压开关，但用户决定不用；**GPIO42 已释放**，
固件不配置或读取按压 GPIO。当前应用不初始化摇杆，两轴实体方向、
旋转后的正负方向与校准仍须装配后核对，不能当成已通过硬件测试。

## RTC：PCF8563T

载板 J5 SDA 接 GPIO15、SCL 接 GPIO16，VCC 接 3.3 V、GND 共地；
CLK 和 INT 保留物理孔位但不接信号。确认模块的 I2C 上拉接到 3.3 V，
没有上拉时须补齐。固件 `RTC_SDA_PIN` / `RTC_SCL_PIN` 已预留对应编号，
当前应用尚未初始化 RTC，也没有新增 RTC 驱动。

## 麦克风：INMP441（I2S）

| 模块信号 | ESP32-S3 接线 | 作用 |
|---|---|---|
| SD | **GPIO17** | 麦克风串行数据输入 |
| WS | **GPIO39** | 声道选择 / 帧时钟 |
| SCK | **GPIO40** | 位时钟 |
| L/R | GND | 选择左声道，与固件的左声道采集一致 |
| VDD | **3.3 V** | 按模块额定电压供电，不接 5 V |
| GND | GND | 共地 |

录音使用 16 kHz、32-bit I2S 左声道采样，转换为 16-bit 单声道 PCM。
SD 是麦克风输出，不能与放大器 DIN 相接。

## 扬声器放大器：MAX98357（I2S）

| 模块信号 | ESP32-S3 接线 | 作用 |
|---|---|---|
| DIN | **GPIO41** | 音频数据输出 |
| BCLK | **GPIO40** | 与麦克风 SCK 共用位时钟 |
| LRC / LRCLK | **GPIO39** | 与麦克风 WS 共用帧时钟 |
| VIN | **开关输出 5V（5V_SW）** | 载板 J4 第 7 脚接 J7 第 2 脚，并与开发板 5V 共用该网络；核对模块额定范围，逻辑信号仍为 3.3 V |
| GND | GND | 与主控和麦克风共地 |
| SD / MODE | **GPIO47** | 平时输出低电平关断；播放时输出 3.3 V 高电平使能左声道 |
| GAIN | **GPIO21** | 默认设为无上下拉的输入（高阻），模块使用约 9 dB 默认增益；可在菜单切换为输出低电平（约 12 dB） |
| SPK+ / SPK- | 扬声器两端 | 不将扬声器负极接主控 GND |

播放使用 16 kHz、16-bit 双声道（同一单声道样本送至左右声道），
适配放大器不同声道选择配置。**只接 DIN/BCLK/LRC 不够**：
VIN 和 GND 必须有正确供电，确认 SD/MODE 没有被拉低（关断）。
GPIO47 控制 SD/MODE，只在播放 I2S 数据时拉高；GPIO21 控制 GAIN，
默认高阻，不对模块施加 3.3 V；如需提高增益，可在
`idf.py menuconfig` → `Minibox hardware test` 启用 12 dB 设置。
这两个引脚不能再用作摇杆输入；不应同时将 SD/MODE 硬接 3.3 V 或 GND。
若实际模块并非 MAX98357A，请先核对其 SD/MODE 与 GAIN 的电气定义。
供电和扬声器阻抗须符合模块额定值；不要直接由 ESP32 GPIO 驱动扬声器。
GPIO40/39 仅供这两个模块共享，固件先停止并释放麦克风 I2S 通道，
再配置放大器 I2S 通道，两者**不会同时工作**。空闲和录音时放大器
SD/MODE 拉低、DIN 保持低电平。

## 音频半双工测试

按住 GPIO5 按钮后，稳定 30 ms 立即开始录音；继续按住最多录制
**3 秒**，满时停止采集并等待松开。松开后播放本次录音，提前松开则
立即停止录音并播放。播放期间新的按钮操作不触发新录音；播放完毕、
GPIO5 松开后重新就绪。GPIO4/6/7 不参与音频控制。
屏幕显示四个按钮和录音、等待松开、播放或错误状态。
录音在 8 MB PSRAM 中使用 **96000 字节（约 94 KiB）** 的缓冲区，
不写入 Flash；音频报错时屏幕保持错误状态，排查串口日志后复位。
未连接麦克风或声道选择不正确时可能录到静音。
若串口显示 `Mic: ... nonzero=...` 且 `Playing ...`，却没有声音，
优先测量放大器 VIN 对 GND 电压及播放期间 SD/MODE 对 GND 电压（约 3.3 V），
然后检查 SPK+/SPK-、扬声器阻抗与 DIN=GPIO41；I2S 软件调用成功
不能证明模块已经上电或解除关断。

## 板载 RGB LED

| 参数 | 值 |
|---|---|
| 控制引脚 | **GPIO48** |
| 控制方式 | WS2812 单线时序，RMT 输出 |
| 固件行为 | 启动时发送全零 RGB 数据，将板载灯熄灭，随后保持引脚低电平 |

仅拉低 GPIO 不会清除 WS2812 已锁存的颜色，因此固件会先发送黑色数据。
GPIO48 与屏幕背光 GPIO9 独立；关闭板载灯不影响屏幕。
板上若还有独立电源指示灯，则不能通过 GPIO48 关闭。

## 接线检查与上电

1. 断电检查 GPIO9–14 的屏幕信号顺序，确认 LED 是控制端还是供电端。
2. 检查四个机械轴触点分别接 GPIO4/5/6/7 与 GND，无 VCC；CC1/CC2 各自 5.1 kΩ 下拉。
3. 检查麦克风 SD=17、WS=39、SCK=40，放大器 DIN=41、LRC=39、BCLK=40、
   SD/MODE=47、GAIN=21，RTC SDA=15/SCL=16，
   INMP441 L/R 接 GND，扬声器两端只接放大器输出。
4. 连接开发板 USB-UART 接口，在当前电脑使用 COM8 烧录。
5. 上电确认屏幕显示四个按钮状态；按住 GPIO5 录音，松开后听回放。

[`固件说明`](../esp32_idf_s3n16r8/README.md)；
模块机械尺寸及外壳安装参数见
