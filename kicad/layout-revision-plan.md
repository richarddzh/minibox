# 载板纠错与重新发布实施计划

2026-10-10；只修改 `kicad` 模块载板，不修改独立集成工程或历史外壳。
以下对应用户十项要求。所有阶段都以实际保存 PCB 为依据；不使用布局生成器
覆盖已有布线。工厂审核、订单提交、付款与实物验收分别记录，不混为完成。

## 1. 基线与保护

- 检查 Git 状态；将实际 PCB、项目和基线 DRC 备份到会话 artifacts。
- 读取真实焊盘、网名、四层铜区、规则、采购型号及已核验的嘉立创库 datum。
- 保持板框 94.5×117 mm、R5、四个安装孔和上排键位置不变。
- 本工程无原理图，只能执行 PCB DRC/网络核验，不能宣称 ERC 通过。

## 3. 机械布局

| 用户项 | 实施及边界 |
|---|---|
| 4 摇杆 | 向左贴近边缘；后续要求左侧距铜皮边界至少1 mm，按更保守的实体与焊盘均满足落实：中心(16.8,95.5)，实体至X=6 mm覆铜边界1.05 mm、焊盘铜约1.22 mm。只允许 Ø30 活动圈越界；较旧板左移3.95/上移2 mm以避螺丝方形，不改安装孔。 |
| 5 下排键 | 两键一起右移，保持19.05 mm节距和行距。这里“第二排中心”解释为整排中心，不是左下键中心。精确2/3需右移3 mm，会使18 mm键帽侵入右下螺丝区1.375 mm；无人响应澄清时优先不重叠，右移1.425 mm，保留0.20 mm方形区间隙，整排中心落在左上键约58%宽度处。不得宣称已精确达到2/3。 |
| 6 麦克风距离 | 固定Y=90.25 mm，按最终摇杆活动圈及四个18 mm键帽，数值最大化水平移动时的“最小边缘间隙”。保存最优X、目标间隙及比邻位置检验。 |
| 7 电源端子 | J8/J9左移并上移，J8真实本体上沿对齐ESP32估计本体下沿Y=45.97 mm；保持两组间距、针脚网络和进线朝左，J7保持朝右。检查实际封装凸耳、公差courtyard、铜到边及分界带。 |

## 4. 布线与验证

- 只删除/重布受移动或改网影响的网络；保留 RTC、屏幕和无关已验证布线。
- 信号0.20 mm，3V3 0.65 mm、5V 0.80 mm；普通过孔0.60/0.30 mm。
- 走线至异网焊盘至少0.30 mm，5V焊盘至少0.50 mm；不降低全局规则。
- 检查45°转弯、I2S实际In1/In2参考地、换层回流；填铜后执行全严重级DRC。
- 后续要求减少不必要地过孔：逐个候选删除/填铜，保留每个信号/电源换层
  3 mm内地回流、实际GND连通及I2S参考铜，不为减少数量删除必要回流孔。
- 新增/更新发布门槛：实际GPIO和麦克风六针、下排/螺丝区、摇杆实体在板内而
  活动圈可越界、麦克风水平最大最小间隙、电源本体上沿及左右进线。
- 固件增量构建，不烧录；复查所有当前接线说明，不修改历史记录来冒充新版本。

- 全BOM/CPL包含17个物理件，J3拆成两个1×3；不把仅两个电阻的SMT清单用于全装配。
- 导出四层Gerber、阻焊/丝印/外形、PTH/NPTH，逐铜层和钻孔对位核验。
- 更新装配图、正反/斜视渲染、中文图例、中心/角度报告、manifest和全审核ZIP。
- 旧网站快照只属于旧PCB哈希；新版必须上传、预览、存档、刷新并读回。
