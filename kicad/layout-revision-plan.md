## 已采用的决定

| 项目 | 当前实现 |
|---|---|
| 四键 | 指定 CPG151101D13 直接焊接，GPIO4/5/6/7；第四键只显示状态 |
| 功放 | GAIN21 / SD47，避免与第四键、RTC 冲突 |
| RTC | SDA16 / SCL15，交换后避免交叉 |
| 麦克风 | SD17 / WS39 / BCLK40 |
| 摇杆 | 指定 YV13S 直接焊接、竖放；滑动端 GPIO1/2 |
| 摇杆按压 | 用户取消；四个按压脚 NC，GPIO42 释放，驱动不配置按压 GPIO |
| CC | J9 独立 CC1/CC2，各经一个 0402 5.1 kΩ 下拉到 GND |
| 机械轴布局 | 19.05 mm 标准节距，下排半单位错位，18 mm 键帽包络 |
| 红线 | Y76，两侧各2 mm安装隔离带 |
| 活动空间 | 摇杆(20.75,97.5)、直径30 mm；麦克风(46.5,90.25)，上沿与键帽齐平 |
| 上部模块 | 功放下缘不得低于键帽上缘；RTC含电池留出间隙 |
| 端子 / ESP32 | 进线全部向外；天线本体留在板内，四层禁铜 |
| 端子采购适配 | J7=C72334，J8/J9=C8465；7孔Ø1.50、盘Ø2.60；J8/J9一起上移1 mm，凸耳/公差包络避开分界带 |
| 板框 | 紧凑 94.5×117 mm、R5；孔距84.5×107 mm |

两款精确封装以指定 PDF 的孔位图和视角为依据。无须识别不用的按压触点
配对，不借用通用 MX/摇杆封装，不猜测其电气连接。RTC、功放、ESP32
及麦克风尺寸保留为明确安装包络，实物和外壳匹配仍须确认。

## 验证及资料流程

基线 PCB/项目/脚本已保存到会话 artifacts，基线 DRC 为0违规/0未连接。
先生成新布局，再布I2S、键控/CC、SPI、模拟轴/RTC/功放控制及电源。
普通信号0.20/0.20 mm，过孔0.60/0.30 mm；电源按专用宽度布线。
四键整体右移1.60 mm，保持原标准节距/错位；摇杆左移1.25/下移4.50 mm，
麦克风左移2.00/下移2.50 mm。麦克风距键帽约1.22、距摇杆约2.00 mm，
摇杆活动圈距板边0.75、距螺丝保护区约0.77 mm；新边缘裕量须实物复核。
异网焊盘走线间距至少0.30 mm，5V焊盘保持0.50 mm。
消除真实间距、直角/锐角、热焊盘及丝印问题，不降低全板规则或批量忽略错误。
填铜后检查真实 In1/In2 参考地及未连接，导出脚本再核对 GPIO 与机械间隙。
固件四键及GPIO迁移已构建，取消按压后再次增量构建；不自动烧录。

最终资料路径见载板 README。Gerber 和钻孔与贴片 BOM/CPL 分开；
THT 插件、轴、摇杆及母座按独立 BOM/坐标/逐孔图审核。
HTML 和渲染必须解释真实 PCB 与模块预留包络的区别。
旧 v1.0 导出件不能当作当前版本发送或下单。
