# Minibox model-v2

独立两件式载板外壳。尺寸、独立渲染、实际截面和装配说明见
[外壳设计与装配报告](fit-review.html)。HTML可离线打开，需保留同目录的
`report-data.js`和`renders`文件夹。原版`models`不变。

## 当前规格

| 项目 | 规格 |
|---|---|
| 外壳 | 120×136×109.804 mm；侧壁2.4、底板4、盖板3 |
| 外形 | 水平操作台Z21.6，经R4接垂直段，再经R6接65°屏幕面；屏幕后仰25° |
| 屏幕 | 直接开窗85.52×57.68、R6；PCB108.04×61.74，承托面局部n=−9 |
| 屏幕位置 | 斜面基准Y55.8/Z46，沿面中心s34.5，表面投影中心Z77.268；上方余量约1.208 |
| 摇杆 | 孔Ø30，中心(24.55,36.5)；用户帽底约测Ø26.4，静态单侧余量1.8 |
| 喇叭 | 左壁X0，中心Y104.8/Z50.3；四个空心螺母柱与底壳一体 |
| 后壁接口 | 上开关(X48,Z79)；下Type-C(X38,Z50.5)/(X58,Z50.5)，三角形居中稍左 |
| 载板 | `kicad\minibox-carrier.kicad_pcb`，94.5×117、R5、厚1.6；原孔位和操作件位置不变 |

X按正面左右，Y向背面，Z向上。局部s沿屏幕面向上，n垂直屏幕面向机外。
盖板屏幕区是原3 mm面板上的直接通孔，内面n=−3，屏幕前表面n=−4，保留1 mm装配间隙。
显示窗口中心相对PCB左移2.26；R6角部会遮挡显示矩形少量角落。

摇杆孔完全位于水平面；Ø29是运动接受上限，不是实测扫掠直径。
摇杆本体按YTL J13厂家图的中央框/电位器和侧按键分段包络，并计入尺寸公差。
键盘保持两排错位的连通孔，每个18×18键帽每侧预留1；仅后排孔后缘轻微进入R4圆弧，
不切竖直直段或屏幕斜面。麦克风使用内Ø16、外Ø20.8、顶Z31、声孔Ø6的独立圆罩。

## 避让和实物条件

- 屏幕、背面元件、右上8×42×12插头、三个安装耳及完整斜撑均纳入检查。下斜撑65°，左上60°，台座Ø8、深10。
- 喇叭27.5±0.2方腔、厚13±0.2，含螺钉头和首段引线；左壁局部厚3。柱高3.4、外Ø7.1、孔Ø4.7×深5.2，盲底1.2，使用M2.5×6。
- 现用ESP32 USB线可插上且抵住左壁，已由用户实物确认。保留X2.4…27.75、Y88…122、Z20.6…32.6占用带；侧壁为已知接触，不作为1 mm空气间隙。
- 面板Type-C已有螺纹Ø10.5×14.5、外头Ø13.8×2、螺母厚3/外接圆约Ø16.17的记录。内壁以内Ø12×30完整后部是设计接受包络，并非已识别SKU的实测总长。
- 开关按内侧Ø24×30加10线尾、外部Ø28×12动作包络；RTC按板顶以上40高竖装，含插座和模块整体。
- 功放含排母23.7高，再加10出线预留。喇叭工具路径包含Ø4刀头及后方Ø8×40操作空间；不保证任意电批、手柄或松散线束。

用户确认的USB插线状态不推广到其他线材。喇叭耳厚/偏距、开关卡扣、各模块堆叠和插头实际外形仍需首件核对。
来源见[硬件规格与来源](..\hardware_references\enclosure-hardware-specs.md)，不使用同名IC尺寸代替整块模块。

## 装配

1. 不安装屏幕、RTC、摇杆帽、USB线和盖板。载板上其余模块按模型包络安装。
2. 正面看左边抬高17°，整板向前偏1；下降至PCB中心底面Z26.5后摆平。
3. 向后移1恢复孔位，再降至支柱面Z9，使用M2.5×6固定。
4. RTC从开放前部送入，在模块底面Z55横移至排母上方，然后向下就位。
5. 安装面板硬件与屏幕，接线并整理，最后安装摇杆帽和盖板。

路线按逐段连续扫掠检查，旋转每1°取相邻姿态凸包并外扩0.1。
它不代表可携带USB线强行装入，也不验证夹持工具、插拔力或任意软线形状。打印后先松装确认，勿强压。

## 文件

| 文件 | 用途 |
|---|---|
| `minibox-enclosure.scad` | 参数模型；`part="assembly"`、`show_modules=true`查看元件包络 |
| `bottom.stl`、`lid.stl` | 两件外壳，保持装配坐标 |
| `bottom.3mf`、`lid.3mf` | 与STL相同的网格，不改变相对位置 |
| `bottom-y-up.stl`、`lid-y-up.stl` | 查看/打印方向版本；盖板包含侧立变换，不是新增零件 |
| `fit-review.html` | 21张整机及独立零件图、12个实际截面、尺寸与装配要求 |
| `verification.json` | 源码/打印件哈希、包围盒、体积及检查记录 |
| `renders\manifest.json` | 图像来源和文件哈希 |

普通底壳/盖板可按装配坐标叠放；Y-up文件不能与普通坐标文件混用。
切片时确认方向、支撑和打印公差。源码和SVG的SHA-256按LF换行计算，二进制文件按原始字节计算，
避免Git换行转换影响配套校验。文件哈希不代替实物装配。

## 重新导出

在本目录运行：

```powershell
Set-Location C:\gitroot\minibox\model-v2
python -m unittest discover -s .\tests -p test_mesh_checks.py
python .\tests\check_enclosure.py --openscad "C:\Program Files\OpenSCAD\openscad.com" --output .
python .\render_models.py --openscad "C:\Program Files\OpenSCAD\openscad.com"
```

完整检查包括PCB孔位、元件包络、键帽行程、连续装入、支撑和盲孔实体，以及封闭单连通、0.001 mm精度下的网格拓扑。
全部通过后才更新打印文件；`--export-only`不代表完成装配检查。
